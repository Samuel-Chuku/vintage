Privacy

Stay shielded all the way to the exit.

Guides today tell you to unshield before depositing, because shielded deposits get frozen. A Vintage proof lets the deposit stay shielded and still clear. This page lists exactly what each party sees when you use it.

03 / What we keep

One counter. Nothing else.

Each finished check adds 1 to a daily total, keyed by the UTC date, the event and the verdict. A check against your own height is counted as "custom height", without the height. That is the whole record.

No transaction ids, no IP addresses, no times of day, no user agents. The web server in front of the API has access logging turned off, for plain HTTP as well as HTTPS. The totals are public, so you can see exactly what is stored.

04 / Trade-offs

What a proof does give away.

An old anchor is visible
Every Vintage send

Most wallets anchor a few blocks back. A Vintage send anchors further back, and anyone reading the chain can see that. It says nothing about who you are or how much you sent, but it does mark the transaction as one that chose to prove its age.

Use it when you deposit somewhere that already knows you, such as an exchange account.

The receipt-account link
Optional · discloses a key

For coins received after an event, the link check shows the rail one single-use receipt account's viewing key. That reveals the funding payments, the amounts received, the receipt address and the deposit. Nothing from your other accounts. The viewing key cannot spend.

Our API drops the key when it answers: never written to disk, a log or a cache. Better still, the rail runs vintage link verify itself, so the key goes to nobody else. Rotate to a fresh receipt account for every use.

05 / Use nobody

Check without us.

The verifier is the same code as the API. Run it on your machine and the only other party is the lightwalletd server you choose. Point it at your own Zcash node and there is no other party at all.

Exchanges can run vintage-api next to their own node, so nobody, including us, learns which deposits they check. See the integration section.
